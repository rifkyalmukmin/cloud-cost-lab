# LinkedIn Description — Cloud Cost Lab

## Project Section

**Cloud Cost Lab** — GCP FinOps & Cloud Cost Optimization Platform

Built a comprehensive FinOps platform that helps engineers understand where cloud money goes and how to optimize it. The system aggregates GCP billing and utilization data, identifies idle and oversized resources, estimates potential savings, and generates evidence-based recommendations requiring human approval before action.

Key technical achievements:
- Integrated GCP Billing Export (BigQuery) with cost-safe query patterns
- Built 5-rule recommendation engine with priority scoring and lifecycle tracking
- Implemented 30-day cost forecasting with confidence ranges
- Designed AI advisor with read-only safety constraints
- 329 automated tests, CI/CD with security scanning, Terraform infrastructure

Tech: Python (FastAPI), TypeScript (Next.js), GCP, Terraform, GitHub Actions, Docker
